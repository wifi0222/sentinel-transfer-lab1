# 威胁模型与安全控制

## 资产和信任边界

需要保护的资产包括用户凭据、会话令牌、文件内容、文件元数据、服务端存储目录和审计记录。浏览器、互联网、TLS 终止点、应用进程、SQLite 数据库与磁盘存储之间均视为信任边界。拥有主机管理员权限的攻击者不在本实验的应用层防护范围内。

## 主要威胁

| 威胁 | 控制 | 剩余风险 |
|---|---|---|
| 中间人攻击 | TLS 1.2+、本地 CA、可选 mTLS、HSTS | 用户错误信任伪造 CA 时仍可能受影响 |
| 密码泄露 | scrypt N=32768、随机盐、强密码策略、登录限频 | 客户端终端被控制时无法保护输入密码 |
| 令牌盗用 | 15 分钟访问令牌、HttpOnly Strict Cookie、令牌族轮换/重放检测、一次性 WSS 票据、每次访问回查账户和密码版本 | 单次请求期间发生的并发撤销存在极短竞态 |
| 管理员抢注 | 公开注册固定为 user；管理员仅能由本机交互命令创建；禁止静默提升已有账户 | 主机管理员权限可直接操作数据库，不在应用边界内 |
| SQL 注入 | 所有值使用参数化语句，标识符不接收用户输入 | 依赖库缺陷需要通过审计和升级处理 |
| 路径穿越 | 显示名校验；磁盘路径只使用服务端 UUID | 主机级文件系统篡改不属于应用层边界 |
| 越权访问 | 每次查询同时匹配资源 ID 与 user_id | 管理员数据库权限需单独保护 |
| 文件篡改 | 分块 SHA-256、整文件 SHA-256、大小和偏移验证、fsync | SHA-256 的碰撞风险在本场景可忽略 |
| 暴力破解 | IP 限频、用户名/IP 失败计数、账户全局失败计数、指数退避和统一错误 | 大规模低频分布式攻击仍需边缘风控 |
| DDoS 和资源耗尽 | IP 限频、连接/消息/文件上限、用户配额、上传预留、磁盘余量、带宽限制、背压、Docker 资源限制 | 大规模分布式攻击仍需边缘防火墙或 CDN |
| 上传中断和崩溃 | WAL、FULL 同步、先落盘再记录分块、恢复缺失分块、原子 rename | 极端磁盘故障仍需外部备份 |
| 同名覆盖和审计篡改 | 同名文件显式版本化；审计表 UPDATE/DELETE 触发器拒绝修改 | 拥有数据库文件写权限者可离线替换数据库 |
| XSS 与点击劫持 | Vue 默认转义、严格 CSP、frame-ancestors none、X-Content-Type-Options | 新增富文本功能时需重新评估 |

## 安全运维要求

正式部署必须使用可信 CA 签发的证书，将 CA 私钥离线保存，定期轮换 JWT 密钥和用户凭据，限制数据目录的操作系统权限，并对 SQLite 数据库与文件目录做一致性备份。审计日志只记录标识和事件，不记录密码、令牌或文件内容。数据库迁移在事务中按 `schema_migrations` 版本执行；升级前仍应备份。
