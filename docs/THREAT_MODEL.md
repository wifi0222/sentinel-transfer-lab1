# 威胁模型与安全控制

## 资产和信任边界

需要保护的资产包括用户凭据、会话令牌、文件内容、文件元数据、服务端存储目录和审计记录。浏览器、互联网、TLS 终止点、应用进程、SQLite 数据库与磁盘存储之间均视为信任边界。系统采用应用层与主机层分层保护：应用负责认证、授权、完整性和资源约束，主机层通过最小权限、访问控制、完整性监控和一致性备份保护运行环境。

## 主要威胁

| 威胁 | 核心控制 | 纵深部署衔接 |
|---|---|---|
| 中间人攻击 | TLS 1.2+、本地 CA、可选 mTLS、HSTS | 生产证书信任由操作系统或企业信任库统一治理 |
| 密码泄露 | scrypt N=32768、随机盐、强密码策略、登录限频 | 终端防护与安全输入环境共同保护凭据入口 |
| 令牌盗用 | 15 分钟访问令牌、HttpOnly Strict Cookie、令牌族轮换/重放检测、一次性 WSS 票据、实时状态回查 | 短令牌窗口与审计追踪形成快速处置闭环 |
| 管理员抢注 | 公开注册固定为 user；管理员由本机交互命令创建；拒绝静默提升已有账户 | 主机与数据库权限采用最小授权和独立审计 |
| SQL 注入 | 所有值使用参数化语句，标识符不接收用户输入 | 生产依赖审计与版本升级保持供应链安全 |
| 路径穿越 | 显示名校验；磁盘路径使用服务端 UUID | 数据目录 ACL 与完整性监控保护主机文件系统 |
| 越权访问 | 每次查询同时匹配资源 ID 与 user_id | 数据库管理权限按运维角色独立保护 |
| 文件篡改 | 分块 SHA-256、整文件 SHA-256、大小和偏移验证、fsync | 一致性备份保留可验证的长期恢复副本 |
| 暴力破解 | IP 限频、用户名/IP 失败计数、账户全局失败计数、指数退避和统一错误 | 边缘风控聚合识别分布式低频尝试 |
| DDoS 和资源耗尽 | IP 限频、连接/消息/文件上限、用户配额、上传预留、磁盘余量、带宽限制、背压、Docker 资源限制 | 防火墙、反向代理或 CDN 承担网络边缘流量治理 |
| 上传中断和崩溃 | WAL、FULL 同步、先落盘再记录分块、恢复缺失分块、原子 rename | 数据库与文件目录执行一致时间点备份和恢复演练 |
| 同名覆盖和审计篡改 | 同名文件显式版本化；审计表 UPDATE/DELETE 触发器拒绝修改 | 远程只追加审计存储强化跨主机追溯能力 |
| XSS 与点击劫持 | Vue 默认转义、严格 CSP、frame-ancestors none、X-Content-Type-Options | 富文本扩展沿用白名单净化与安全评审门禁 |

## 安全运维配置

生产部署使用可信 CA 签发的证书，将 CA 私钥离线保存，定期轮换 JWT 密钥和用户凭据，收敛数据目录的操作系统权限，并对 SQLite 数据库与文件目录执行一致性备份。审计日志只记录标识和事件，不记录密码、令牌或文件内容。数据库迁移在事务中按 `schema_migrations` 版本执行，版本升级与一致性备份共同构成可回滚发布流程。
