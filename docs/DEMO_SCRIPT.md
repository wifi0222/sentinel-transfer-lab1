# 演示视频脚本

建议时长 8 至 12 分钟，完整展示以下内容。

1. 展示项目目录和 Git 提交记录，说明客户端、服务端、文档和测试的组织方式。
2. 运行 `npm install`、`npm run build`、`npm test` 与 `npm audit --omit=dev`，展示构建、测试及零已知生产依赖漏洞。
3. 运行 `scripts/start-dev.ps1`，解释本地 CA、HTTPS、WSS 与随机 JWT 密钥。
4. 使用 `scripts/create-admin.ps1` 在本机创建管理员，再公开注册普通用户，说明公开注册绝不会产生管理员。
5. 上传并下载一个文件，使用 `Get-FileHash -Algorithm SHA256` 对比原文件和下载文件。
6. 上传较大文件时断开网络或关闭页面；恢复后重新选择相同文件，展示缺失分块续传。
7. 同时上传多个文件，展示并发队列和逐项完整性结果。
8. 在管理员界面限制普通用户带宽和配额，再禁用账户，展示旧会话立即失效。
9. 简要展示 `docs/PROTOCOL.md` 的帧格式和时序图，说明长连接、ACK、偏移量与哈希字段。
10. 展示重复注册、刷新令牌重放、路径穿越、错误分块哈希、错误登录退避和越权访问测试的结果。
11. 展示 Dockerfile 和 compose 加固配置，包括非 root、只读根文件系统、capabilities 清除与资源限制。
12. 以分层防御收束演示：应用层完成认证、授权、完整性、资源约束和审计，边缘防火墙、主机最小权限与一致性备份构成生产部署的纵深保护。
